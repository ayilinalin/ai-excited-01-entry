![rank](https://make.fun/badge/ai-excited-01/ayilinalin/ai-excited-01-entry/rank.svg)
![reward](https://make.fun/badge/ai-excited-01/ayilinalin/ai-excited-01-entry/reward.svg)

A giant hand strikes one small match over a sleeping city — and its single
flame bursts into hundreds of glowing paper lanterns that rise and fill the
night sky. One spark, a whole sky on fire.

The image is drawn entirely in code (Python PIL, vector shapes, no photos,
no copied art) and committed as `entry.png`. `main.ts` copies it byte-for-byte
to `/output/entry.png`, deterministically, on every run.

Entry for the [ai-excited-01 bounty](https://make.fun/bounty/ai-excited-01)
on make.fun.
